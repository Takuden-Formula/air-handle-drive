# エアハンドル・ドライブ

カメラの前で**見えないハンドルを両手で握るポーズ**をして、画面の学生フォーミュラ EV を運転するレースゲームです。**1回 200 円**で、タイムに応じて景品を **2〜4 個**もらえます（ESP32 の景品機が出す）。1回目の結果が気に入らなければ、**1回だけ**再挑戦できます。

```
Webカメラ → Chrome（index.html：MediaPipe Pose で両手首の傾き＝ハンドル角を読む → 疑似3Dレース）
                 └─ USB シリアル（Web Serial）→ ESP32 → サーボで景品を出す（じゃんけんロボと同じ景品機）
```

- **インストール不要・オフラインで動く**：Chrome（または Edge）と Windows 標準の PowerShell だけで動きます。認識モデルとライブラリは同梱です。
- **景品機なしでも遊べる**：「景品 ○ 個！」が出たらスタッフが手渡しします。
- **記録は PC のフォルダに保存**：設定で選んだフォルダの `records.csv` に1回ごとに書き足し、起動時にそこからランキングと集計を読み込みます。

## 1. 起動
1. フォルダを置く（例：`OneDrive - 学校法人　拓殖大学\プログラム\エアハンドル・ドライブ\`）
2. **`起動.bat` をダブルクリック** → カメラを「許可」
3. 本番は **`起動_全画面.bat`**：アドレスバーなしの窓で開き、**最初に画面をクリック（またはキーを押す）と全画面**になります
   - **Esc で全画面解除**、F キーでもう一度全画面
   - 終了はウィンドウを閉じてから、黒い窓を閉じる

> `index.html` を直接開いても動きません。必ず `.bat` から起動してください。

## 2. 遊び方（受付からの流れ）
```
待機（1回 200円・景品の表）→ お金を受け取ったらスタッフが Enter → コースを選ぶ（市街地／サーキット／高速）→ 5つの赤ランプ → レース
  → 1回目の結果「景品 ○ 個！」→ 受け取る（Enter）／もう1回（R）※1回だけ
  → 景品を出す（景品機が個数分出す）→ 待機に戻る
```
1. 待機画面には **「1回 200円」と、タイムごとの景品の個数の表**が出ています（料金は設定で変えられる）。
2. お金を受け取ったら、スタッフが **Enter** を押す（景品機のボタンでも同じ）。
3. **コースを選ぶ**（下の「コース」）。← → で選んで Enter、1・2・3 キー、カードをクリック、またはハンドルを **左＝市街地／まっすぐ＝サーキット／右＝高速** に 2 秒。30 秒たつと選んでいるコースで始まります
4. 挑戦する人はカメラから **1.5〜2.5m** 離れて立つ（**上半身と両手が映る**位置）。床にテープで立ち位置を貼っておくと楽です。
5. **F1 と同じ 5 つの赤ランプ**が点いて、消えたら GO！ ハンドルを回すように両手を傾けて曲がる。**アクセルは自動**（手を離すと減速）
6. コーン（高速は前を走る車）をよけてゴール！**コーン1本ごとに +1秒**、コースアウトすると大きく減速（カーブの外側の砂利はとくに遅い）。道路の外の**ガードレールにぶつかると火花が出て大きく減速**
7. **景品の個数はタイムで決まる**（最低 2 個、最大 4 個。時間切れ・途中でやめても 2 個）。タイムはコースごと

   | コース（長さ ふつう・110 km/h の初期値） | 4 個 | 3 個 | 理論最速 |
   |---|---|---|---|
   | 市街地 | 43 秒以内 | 50 秒以内 | 36.8 秒 |
   | サーキット | 44 秒以内 | 51 秒以内 | 37.5 秒 |
   | 高速 | 43 秒以内 | 51 秒以内 | 37.1 秒 |
8. 1回目が終わると **「景品 ○ 個！」と、2つのボタン**が出ます
   - **受け取る**：Enter、ボタンをクリック、またはハンドルを**右に**傾けたまま 1.5 秒
   - **もう1回！**（1回だけ・同じコース）：R、ボタンをクリック、またはハンドルを**左に**傾けたまま 1.5 秒
   - 30 秒選ばないと自動で「受け取る」になります
   - 再挑戦したときの個数は、初期値では **1回目と2回目の良い方**（減らない）。設定で「2回目の結果」にもできます
9. 景品機がつながっていれば個数分を 1 個ずつ出します（つながっていなければ「スタッフから受け取ってね」）。本日のランキング（上位5位）とこれまでの最速も出ます

### コース（スタート前にお客さんが選ぶ）
| コース | 特徴 | 障害物 |
|---|---|---|
| 🏙️ **市街地** | ビルの谷間を走る公道コース。**直角コーナー・ヘアピン・シケイン**が続く。両側はコンクリートの壁と金網、街灯・信号・歩道橋・お店の看板 | コーン |
| 🏁 **サーキット** | 縁石・砂利・タイヤバリアのある本格コース（前からのコース） | コーン |
| 🛣️ **高速** | **長い直線と大きなカーブ**、アップダウン。防音壁・照明・緑の案内標識・料金所 | **前を走る車**（60〜70 km/h。追い越す。ぶつかると +1 秒） |

3 コースとも、ふつうの長さで理論最速 37 秒前後になるように長さをそろえています（コースの長さの設定は 3 コース共通）。待機中のデモは 3 コースを順番に走ります。ランキングとこれまでの最速はコースごとです。

レース中は左上に**コースマップ**（黄色＝走った所、赤い点＝自分）が出ます。

### コースの見た目
本物のサーキットに近づけています。
- スタートは**グランドスタンド・ピット・F1 風のシグナル付きゲート**と白いスタートグリッド、ゴールはチェッカーのゲートとスタンド
- カーブには**紅白の縁石**と、外側に**砂利（グラベル）とタイヤバリア**、**紅白の矢印看板**、マーシャルポスト（旗を持った係員）、きついカーブには観客
- きついカーブの手前に**ブレーキの目安の距離看板（150・100・50）**
- 直線は**ガードレール**と広告看板（TAKUDEN FORMULA／拓殖大学 電気自動車同好会 など）と照明塔
- 空は太陽と流れる雲、遠くの山は霞んで見え、上り坂は明るく下り坂は少し暗い
- 車は学生フォーミュラ EV らしく、リアウイング・ロールバー・ディフューザー・**高電圧マーク**・ブレーキで光る**レインライト**付き。コーンに当たるとコーンがはね飛び、コースアウトすると砂ぼこりや芝が舞う
- 描画が重い PC（画面 30 FPS 未満が 3 秒続く）では、自動で**軽量モード**（雲と遠くの林を省く）になります。画面下に `軽量` と出ます

右下のカメラ画面に、骨格と**見えないハンドル**（緑の輪＝握っている判定）が出ます。ハンドルの角度も数字で出るので、うまく曲がれないときはここを見てください。

待機中は車が自動運転で走るデモが流れ、通りがかった人の目を引きます。

## 3. 設定（S キー、または右上の ⚙）
| 項目 | 内容 | 初期値 |

| カメラ | USB カメラと内蔵カメラの切り替え | – |
| コースの長さ | みじかい／ふつう／ながい（3 コース共通） | ふつう |
| **最高時速** | 40〜110 km/h（10 km/h 刻みのスライダー）。110 km/h が車の最高速（下の「車の性能」）。小さい子向けに遅くしたいときに下げる（リミッター） | 110 km/h |
| **料金** | 待機画面に出す 1 回の料金 | 200 円 |
| **景品の個数になるタイム（コースごと）** | 市街地・サーキット・高速それぞれの 4 個・3 個のタイム。それより遅い・完走できないと 2 個。**コースの長さや速度を変えると「理論最速 ＋15% / ＋35%」に自動で設定** | 上の表 |
| **再挑戦したときの景品の数** | 「1回目と2回目の良い方」か「2回目の結果」 | 良い方 |
| **記録を保存するフォルダ** | 「フォルダを選ぶ」で PC のフォルダを選ぶ（下の「記録」） | 未設定 |
| 制限時間 | 過ぎると「時間切れ」 | 90秒 |
| ハンドル感度 | 何度回すとフルに曲がるか（小さいほど敏感） | 45° |
| ハンドルアシスト | カーブで流されにくく、コースアウトしても中央へ戻る（小さい子向け） | 30% |
| 障害物 | コーン（高速は前を走る車）の ON/OFF | ON |
| 景品の残り数 | 0 で「景品切れ」表示（-1 = 数えない） | -1 |

### 車の性能（同好会の車に合わせている）
| 項目 | 値 |
|---|---|
| モータ | デンソー製 36 kW、最大トルク 60 N·m、最高 11000 rpm |
| 減速比 | 10 : 1 |
| タイヤ | 14 インチホイール、外径 0.53 m（仮定） |
| 車重 | 300 kg（運転手込み・仮定） |
| 最高速 | **約 110 km/h**（モータ 11000 rpm で頭打ち） |
| 加速 | 0→50 km/h 約 2.1 秒、0→100 km/h 約 5.8 秒 |

約 5700 rpm（57 km/h）まではトルク一定（60 N·m）で強く加速し、それより上は出力一定（36 kW）でトルクが下がるので加速が鈍ります。アクセルを離すと回生ブレーキで減速します。空気抵抗（CdA 1.2 m²）、転がり抵抗、効率 92%、回生 4 m/s² も仮定です。値は `game.js` の `CAR` で変えられます。

画面左下に速度とモータ回転数（バー付き）が出ます。画面の縮尺は車幅を 1.4 m として合わせています（道幅は約 9.4 m）。

### 走行音
音声ファイルは使わず、Web Audio でその場で合成しています（`sound.js`）。
- **インバータ音**：キャリア音（「ヒュイーン」）。回転数で 1250 → 2500 → 5000 Hz と段が変わり、側帯波が電気周波数に合わせて動きます。トルクを出しているほど大きくなります
- **モータの電磁音**：電気周波数（回転数/60 × 極対数 4。11000 rpm で約 730 Hz）とその倍音
- **ギヤ音**：歯数 17（仮定）のかみ合い音
- **タイヤのロードノイズと風切り音**：速いほど高く大きくなります
- **路面**：砂利のザザザ、芝のボソボソ、縁石のゴトゴト（紅白の間隔に合わせる）
- **当たったとき**：コーンの「ボコッ」、ガードレールの「ガシャン」
- 極対数・キャリア周波数・歯数は仮定なので、`sound.js` の先頭の定数で実車やモータ音再現アプリに合わせてください

### コースと最高時速ごとの理論最速タイム（車の性能から計算）
| 最高時速 | みじかい | ふつう | ながい |
|---|---|---|---|
| 60 km/h | 35 秒 | 65 秒 | 95 秒 |
| 80 km/h | 27 秒 | 50 秒 | 72 秒 |
| 100 km/h | 22 秒 | 41 秒 | 59 秒 |
| **110 km/h（最高）** | **21 秒** | **38 秒** | **54 秒** |

最高時速を下げたり、コースを「ながい」にしたりするときは、制限時間（初期値 90 秒）も伸ばしてください。

### 景品のタイムの目安（ふつうのコース、最高時速 110 km/h、理論最速 37.5 秒）
旧版（加速が一定の物理、理論最速 37.2 秒）でシミュレーションした結果です。今の物理でも理論最速はほぼ同じです。
| 運転のしかた | タイム（ペナルティ込み） |
|---|---|
| 完璧（自動運転） | 37 秒 |
| ふつうの人（反応が 0.4 秒遅れる・手ぶれあり） | 40〜43 秒 |
| ハンドルを全く回さない | 47 秒以上 |

→ 初期値の 4 個 ＝ 44 秒（＋15%）は「上手に運転できれば取れる」、3 個 ＝ 51 秒（＋35%）は「ハンドルを回していればほぼ取れる」難しさです。景品を減らしたいときは 4 個のタイムを 41〜42 秒に下げてください。

### 記録（records.csv）
設定の「記録を保存するフォルダ」で選んだフォルダに `records.csv` を作り、1 回走るごとに 1 行足します（Excel で開けます）。

| 列 | 内容 |
|---|---|
| 日時・受付番号・回目 | 200 円 1 回ごとに受付番号。再挑戦すると同じ受付番号で 2 回目の行ができる |
| 結果・タイム秒・コーン | ゴール／時間切れ／中止、ペナルティ込みのタイム |
| この回の景品数・判定・渡した景品数 | 判定は 受け取り／再挑戦／2回目で確定。実際に渡した数は最後の行にだけ入る |
| コース・最高時速 | 「市街地・ふつう」のようにコースの種類と長さ、そのときの最高時速。前の版の記録（種類なし）はサーキットとして読む |

- 起動時にこのファイルを読み、**本日のランキング・挑戦人数・景品の数**と**これまでの最速**を出します。別の PC で記録したファイルをこのフォルダに置けば、そのまま引き継げます
- フォルダの場所はブラウザが覚えています。ブラウザを開き直すと、**最初に画面をクリックしたとき「このフォルダの編集を許可しますか」と聞かれるので「許可」**を押してください（画面下に `記録: 許可待ち` と出ている間は保存されません）
- フォルダを選ばなくても遊べます（そのときの記録はブラウザの中だけに残ります）

## 4. 景品機（ESP32）
`esp32/janken_prize/` は**じゃんけんロボと同じスケッチ**です。部品、配線、書き込み方法、角度の調整方法はじゃんけんロボの README を見てください（サーボの信号は GPIO18、スタートボタンは GPIO4）。
- ESP32 のボタンは Enter と同じです（待機中ならスタート、結果画面なら「受け取る」）。お客さんの手が届かない所に置いてください
- 景品を出すときは `PRIZE` を個数分送ります。景品機は 1 回で 1 個出して `DONE` を返し、続けて出すには 1.5 秒あける作りなので、`DONE` を待ってから次を送ります（`BUSY` なら待って送り直し、返事が無ければそこで止めて残りはスタッフが渡す）。スケッチは変えていません
- `EV:START`・`EV:LOSE` は LED 演出です

## 5. 困ったとき
| 症状 | 対処 |
|---|---|
| 「両手を見せてね」のまま | 少し下がって、**両手首と両肩**が映るようにする。逆光を避ける |
| 記録が保存されない | 画面下が `記録: 許可待ち` なら画面を1回クリックして「許可」。`記録: 未設定` なら設定でフォルダを選ぶ |
| 景品が足りなかった | 景品機の返事が無いとそこで止まります（多く出さないため）。画面の「○ 個しか出ませんでした」を見て残りを手渡し |
| 曲がる向きが逆 | 設定の「左右反転」を切り替える（カメラによって映像が最初から反転していることがある） |
| 曲がりすぎ・曲がらない | ハンドル感度を上げる／下げる |
| 動きがカクカク | 画面下の「認識 ○ / 画面 ○ FPS」の認識が 15 以下なら、他のアプリを閉じる。`モデル: OK (CPU)` なら Chrome の「ハードウェア アクセラレーション」を ON |
| 音が出ない | 画面を1回クリックする |
| 景品機に接続できない | Arduino IDE のシリアルモニタを閉じる。ケーブルが充電専用でないか確認 |

## 7. 確認状況
- **確認済み**：Chrome（ヘッドレス）で、モデルの読み込み（GPU）→ 待機デモ → F1 スタートランプ → 自動運転でレース → ゴール → 景品ゲット → ランキング表示の一連の流れ。コースの長さとタイムのシミュレーション。ハンドル角度の計算（左右の向き）のテスト
- **未確認**：
  - **実際の人の体での操作感**（開発環境にカメラが無いため）。感度とアシストは実際に遊んで調整してください
  - Windows での `起動.bat` の実行、ESP32 の実機
  - 開発環境では描画が遅かった（3 FPS）ため、なめらかさは実際の PC で確認が必要です。i5 / Iris Xe クラスなら 30 FPS 以上出る見込みです

- **コースの見た目の改良（2026-10）**：Chrome（ヘッドレス）で、待機デモ → スタート → 走行 → ゴールの流れでエラーが無いこと、ガードレール接触・コーン接触・砂利の演出、コースの長さと理論最速タイムが変わっていないこと（自動運転で 37.15 秒、旧版と同じ）を確認。GPU なしのソフトウェア描画で描画だけなら約 48 FPS（旧版 60 FPS）。実機の GPU では差は出ない見込みですが、本番の PC で画面下の「画面 ○ FPS」を確認してください
- **車の性能と走行音（2026-10）**：自動運転で理論最速どおりのタイム（上の表）になること、0→100 km/h が約 5.8 秒、最高回転数 11000 rpm で 110 km/h に頭打ちになることを確認。走行音は 0→110 km/h の加速・砂利・縁石・コーン・衝突を含む 14 秒をオフラインで録音し、音が出ていることと音量の釣り合いを確認。**実際のスピーカーでの聞こえ方は未確認**
